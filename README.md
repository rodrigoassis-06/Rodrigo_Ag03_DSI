# Pesquisa de Satisfação - Empresa TudoWeb

Atividade avaliativa da **Agenda 03 - Desenvolvimento de Sistemas I** (CPS / EAD TEC - Centro Paula Souza).

## 📋 Descrição do Projeto

Programa desenvolvido em **Python** para coletar e analisar a satisfação no atendimento ao cliente da empresa *TudoWeb*.

### Requisitos Atendidos:
- [x] Utilização da estrutura de repetição `for`.
- [x] Coleta de **nome**, **idade** e **opinião** (1: EXCELENTE, 2: BOM, 3: RUIM).
- [x] Aplicação de estruturas de decisão (`if`/`elif`/`else`) para contabilizar as respostas.
- [x] Configurado para **50 entrevistados** (com flexibilidade para testes com 10 entrevistados).
- [x] Apresentação final na tela:
  - Quantidade de respostas **"EXCELENTE"**
  - Quantidade de respostas **"RUIM"**

---

## 🚀 Como Executar o Programa

### Execução manual interativa:
```bash
python pesquisa.py
```

### Execução de teste automatizado com 50 entrevistados:
```bash
python simular_50_testes.py
```
O log com a execução completa também fica salvo em `resultado_execucao_50.txt`.

## 💻 Como Subir para o seu GitHub

Para entregar o link no ambiente virtual da EAD TEC:

1. Crie um repositório no GitHub com o nome (por exemplo: `pesquisa-satisfacao-tudoweb`).
2. No seu terminal dentro da pasta deste projeto:
   ```bash
   git init
   git add .
   git commit -m "Entrega da atividade: Pesquisa de Opinião TudoWeb"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/pesquisa-satisfacao-tudoweb.git
   git push -u origin main
   ```
3. Copie a URL do seu repositório no GitHub e cole no campo de resposta do Ambiente Virtual.
